# Artwork

The launcher and release icon uses an original generic house-and-toggle design
created for Karoo Home Assistant Companion. It contains no Home Assistant or
Android artwork and is distributed under the repository's Apache-2.0 license.

- `karoo-hass-companion-icon.svg` is the canonical rounded-square source.
- `karoo-hass-companion-icon-round.svg` is the legacy round-launcher source.
- `karoo-hass-companion-icon.png` is the release asset generated from the
  canonical SVG.

Home Assistant and its logo are trademarks of their respective owners. This
project's artwork must not be presented as an official Home Assistant mark.
